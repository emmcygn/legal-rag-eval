# Dashboard Deployment

The hosted Streamlit application is an evidence-report viewer. It reads `evidence_benchmark_report_v1` JSON generated by the offline CLI and does not run retrieval or recompute scores.

```bash
python -m pip install -e ".[dashboard]"
python -m legal_rag_eval benchmark
streamlit run streamlit_app.py
```

No API keys are required. The separate `dashboard.yml` workflow imports both current and legacy modules for compatibility, then performs a Streamlit health check. Legacy live-retrieval pages are not exposed in application navigation.
